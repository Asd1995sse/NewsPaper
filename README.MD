# News Portal

Django-приложение для управления новостями и статьями с системой рейтингов и комментариев. А также с функцией censor filters.
Добавлен поиск и инструменты CRUD.
Добавлена авторизация через OAuth (Яндекс)
Добавлено автоматическое создание групп, при помощи команды - `python manage.py create_groups`
Добавлена возможность создания категорий. 
Добавлена возможность подписки на категории.
Исправлена группа commons, теперь выдает автоматически.
Добавлен планировщик с автоматической рассылкой.
Реализована функция проверки email.

Реализованы кнопки в шаблонах для осуществления регистрации, авторизации, выхода из профила, а также возможност ьстать автором.

Для авторизации и провеки прав были созданы 2 приложения.
---
После старта сервера, новости доступны по адресу http://127.0.0.1:8000/news/
Детальный вывод новостей доступен по адресу http://127.0.0.1:8000/news/<news id>/
Страницы: 
- /news/create/
- /news/<int:pk>/edit/
- /news/<int:pk>/delete/
- /articles/create/
- /articles/<int:pk>/edit/
- /articles/<int:pk>/delete/

##  Модели

| Модель | Описание |
|--------|----------|
| `Author` | Автор постов (связь 1:1 с `User`, рейтинг) |
| `Category` | Категория (уникальное название) |
| `Post` | Статья или новость (заголовок, текст, рейтинг, тип, дата) |
| `PostCategory` | Промежуточная таблица для связи `Post` и `Category` |
| `Comment` | Комментарий к посту (текст, рейтинг, дата, автор) |

---

## Методы моделей

### `Post`
- `like()` — увеличивает рейтинг на 1
- `dislike()` — уменьшает рейтинг на 1
- `preview()` — возвращает первые 124 символа текста + `...`

### `Comment`
- `like()` — увеличивает рейтинг на 1
- `dislike()` — уменьшает рейтинг на 1

### `Author`
- `update_rating()` — обновляет рейтинг автора по формуле:
  - сумма рейтингов всех статей автора × 3
  - + сумма рейтингов всех комментариев автора
  - + сумма рейтингов всех комментариев к статьям автора
